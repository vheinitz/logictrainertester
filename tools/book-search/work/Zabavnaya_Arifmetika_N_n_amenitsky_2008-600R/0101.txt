Забавная арифметика 
2-е число 5 = 2 + 3, 
3-е число 8 = 2 + 3 + 3, 
4-е число И = 2 + 3 + 3 + 3, 
5-е число 14 = 2 + 3 + 3 +3 + 3 и т. д. 
Отсюда видно, что любое число нашего рада можно 
составить из первого числа и одной, двух, трех и т. д. 
троек. 
При этом заметьте следующее. 
Чтобы получить, например, третье число, надо 
к первому числу прибавить 2 тройки. Чтобы получить 
четвертое число, надо к первому числу прибавить 
3 тройки. Чтобы получить пятое число, надо к  
первому числу прибавить 4 тройки. Одним словом, чтобы 
получить какое-нибудь число из нашего ряда, надо 
к первому числу прибавить столько троек, сколько 
чисел находится в ряду перед этим числом. 
Например, узнаем тринадцатое число в нашем ряду. 
Для этого к первому числу, т. е. к 2, прибавим 
12 троек, т. е. 36: 
13-е число 2 + 36 = 38. 
Или 24-е число: 
24-е число 2 + 23 х 3 = 2 + 69 = 71.
