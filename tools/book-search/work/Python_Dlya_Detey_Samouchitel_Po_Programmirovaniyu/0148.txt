                          Вычисляя, равен ли нулю остаток от деления x на 2, мы, по сути, про-
                      веряем, можно ли поделить x на две части без остатка. Это удобный спо-
                      соб выяснить, является ли содержимое переменной четным числом, ведь
                      четные числа всегда без остатка делятся на 2.
                          Итак, если значение x четное (if х % 2 == 0:), даем черепашке коман-
                      ду развернуться на 175 градусов влево (t.left(175)). Если нечетное
                      (else), то на 225 градусов (t.left(225)).
