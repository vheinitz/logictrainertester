Иногда программу удобнее писать и тестировать небольшими частями.
Но есть проблема: нельзя создать конструкцию if без блока с кодом, ко-
торый должен выполняться, когда условие if дает True. Точно так же
не получится создать цикл for без тела цикла. Например, этот код рабо-
тает нормально:


       >>> age = 15
       >>> if age > 10:
               print('старше 10')

       старше 10



   Однако если убрать тело if, Python выдаст ошибку:


       >>> age = 15
       >>> if age > 10:

       File "<stdin>", line 2
       ^
       IndentationError: expected an indented block



    Такое сообщение об ошибке возникает, если после какой-либо кон-
струкции должен стоять блок кода, но его там нет (кстати, IDLE не позво-
лит ввести код этого примера). В подобных случаях вместо отсутствую-
щего кода можно ввести команду pass, которая не выполняет действий.
    Допустим, мы хотим создать цикл for с конструкцией if внутри
него, но пока не решили, что будет происходить в теле if (печать сообще-
ния, выход из цикла по break или еще что-то). Можно воспользоваться
pass, и код запустится, несмотря на то что он не завершен.
    Вот конструкция if с ключевым словом pass в качестве блока кода:


       >>> age = 15
       >>> if age > 10:
               pass



   Еще пример использования pass:


       >>> for x in range(0, 7):
       >>>     print('x = %s' % x)
