                                Средствами tkinter можно загружать только изображения фор-
                         !      мата GIF (файлы с расширением .gif). Чтобы вывести изображение
                                другого типа, скажем, PNG (.png) или JPG (.jpg), придется восполь-
                                зоваться другим модулем, например Python Imaging Library (http://
                                www.pythonware.com/products/pil/).

                             Вывести изображение test.gif на экран можно так:


                                from tkinter import *
                                tk = Tk()
                                canvas = Canvas(tk, width=400, height=400)
                                canvas.pack()
                                my_image = PhotoImage(file='c:\\test.gif')
                                canvas.create_image(0, 0, anchor=NW, image=my_image)

                       my_image. Если ваше изображение находится на рабочем столе, нужно
