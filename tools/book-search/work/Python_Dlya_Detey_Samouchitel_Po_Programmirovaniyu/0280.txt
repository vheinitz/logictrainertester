                     PHP
                     PHP (http://www.php.net/) — язык программирования для создания сай-
                     тов. Для разработки на PHP нужен сервер (программное обеспечение, от-
                     сылающее веб-страницы браузеру) с установленным PHP. Необходимые
                     программы можно скачать бесплатно для всех популярных операци-
                     онных систем. Чтобы создавать сайты на PHP, понадобится изучить
                     HTML (простой язык разметки для создания веб-страниц). По адресу
                     http://php.net/manual/ru/tutorial.php можно ознакомиться с обучающими
                     статьями по PHP, а по адресу http://htmlbook.ru/samhtml — с самоучите-
                     лем по HTML.
                         HTML-страница, выводящая фразу «Hello World» в окне браузера, бу-
                     дет примерно такой:


                               <html>
                                   <body>
                                       <p>Hello World</p>
                                   </body>
                               </html>



                            А вот PHP-страница, выводящая это же сообщение:


                               <?php
                               echo "Hello World\n";
                               ?>



                     Objective-C
                     Язык Objective-C (http://www.tutorialspoint.com/objective_c/) очень похож
                     на C (фактически, это расширение языка C). Используют его в основном
                     на компьютерах фирмы Apple. На Objective-C написано большинство при-
                     ложений для iPhone и iPad.
