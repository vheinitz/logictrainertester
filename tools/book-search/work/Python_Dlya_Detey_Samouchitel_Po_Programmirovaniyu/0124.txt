Создание нового файла в Mac OS X
                      Выполните следующие шаги для создания файла test.txt:

                            1. Кликните по значку Spotlight в меню вверху экрана.

                            2. В появившейся строке поиска введите TextEdit.

                            3. В секции Applications должно появиться приложение TextEdit,
                               кликните по нему (также TextEdit можно найти в Finder, в папке
                               Applications).

                            4. Введите несколько строк текста.

                            5. Выберите Format ▶ Make Plain Text.

                            6. Выберите File ▶ Save.

                            7.    В строке ввода Save As введите test.txt.

                            8. В списке Places кликните по вашему имени пользователя — име-
                               ни, под которым вы вошли в систему, или имени человека, кото-
                               рому принадлежит этот компьютер.

                            9.    Нажмите кнопку Save.
