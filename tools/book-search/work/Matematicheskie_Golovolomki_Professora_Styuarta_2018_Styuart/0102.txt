     Почему в результате суммирования кубов получаются
квадраты? Можно найти формулу и доказать таким способом все,
что нам нужно, но существует очень аккуратное наглядное

доказательство того, что I3                   + 23 + З3 +    ...   + п3 =   (1 + 2 + 3 +   ...




+    п)2, для которого не нужны никакие формулы.




                                Визуализация суммы кубов

     На рисунке показан один квадрат со стороной 1, два
квадрата со стороной 2 (образующие куб 2 х 2 х                              2), 3 квадрата
со          стороной 3 (куб 3 х 3 х 3) и т.д. Так что суммарная
площадь этой фигуры представляет собой сумму
последовательных кубов. Следуя вдоль одной из сторон (к примеру, верхней),

видим 1 + 2 + 3 + 4 + 5, то есть сумму последовательных
чисел. Но площадь квадрата равна квадрату его стороны. Готово!

     Если вам непременно нужна формула, то мы знаем, что
(1 + 2 + 3 +              ...   +   п)    =
                                              п(п + 1)/2, а возведение в квадрат
дает I3 + 23 + З3 +                 ...   + п3    =
                                                      п2 (n + 1) 2/4.
