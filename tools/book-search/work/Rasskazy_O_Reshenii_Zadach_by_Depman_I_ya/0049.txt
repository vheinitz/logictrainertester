Кто из учеников решил задачи? 
Решение 
Для сокращения письма введем обозначения. 
Заявление „ученик С решил задачи" записываем 
равенством С=1; если „С не решил", то С = 0. 
Такие же обозначения употребим относительно 
каждого школьника. 
По смыслу задачи в одном из пяти ответов обе 
буквы равны нулю (оба ученика не решили задачи), 
в четырех остальных ответах одна буква равна нулю, 
другая — единице (один ученик решил, другой не 
решил). 
1) Предположим, что в первом ответе С = 0, G = 0. 
Тогда по третьему и пятому ответам Т=\ и #=1, 
по второму ответу D = 0 и по четвертому ответу /= 1. 
Оказалось, что три ученика— Ту Η и /—решили задачи, 
что противоречит условию. Предположение С = 0 и 
G = 0 невозможно. 
2) Предположим, что во втором ответе D=0, 
Т=0. По третьему и четвертому ответам С=\ и 
/=1, по первому ответу G = 0, по пятому ответу 
Я = 0. 
Из шести учеников решившими задачи оказываются 
только двое: Си/. 
Все другие предположения приводят к  
недопустимым ответам, —что задачи решили более чем двое 
учащихся.
