Определив с помощью часов период колебаний  
маятника (для этого достаточно подсчитать число  
колебаний, совершаемое маятником за достаточно  
длительное время, а затем вторую величину разделить на 
первую), рассчитаем по приведенной формуле длину 
подвеса /, т. е. высоту комнаты, взяв значение g, 
соответствующее данной географической широте, из 
физического справочника или приняв его, для  
простоты, равным 9,8 м/с2. Таким же образом  
определяем далее длину комнаты и ее ширину, а затем 
простым перемножением всех трех измерений — 
объем. 
Если длина маятника окажется слишком большой 
(комната велика) и измерять его период будет  
неудобно, можно определить половину  
соответствующего размера, сложив нить вдвое. 
45. Проще всего, видимо, поступить так.  
Постепенно изменяя длину маятника, изготовленного из 
нити и шарика, добьемся совпадения периодов  
маятника и метронома. Измерив после этого длину нити / 
и радиус шарика R, по формуле 
рассчитаем период маятника, который и будет равен 
периоду метронома. Эт^ операцию следует проделать 
для как можно большего числа положений грузика 
на шкале метронома. 
Можно и не менять длину нити. В этом случае 
период маятника рассчитываем только один раз.  
Затем для каждого положения грузика метронома  
определяем скольким ударам соответствует целое число 
колебаний маятника. Умножая число качаний  
маятника на его период, находим время работы  
метронома. Разделив эту величину на число ударов  
метронома, находим его период. Более подробно этот  
способ рассмотрен далее в решении задачи 93. 
46. Поставим лестницу около стены высокого

t == V2% = V(2 • 4,9 м)/(9,8 м/с2) = 1 с.
