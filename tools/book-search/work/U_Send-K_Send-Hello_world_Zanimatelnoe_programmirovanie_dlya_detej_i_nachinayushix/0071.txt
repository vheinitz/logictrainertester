Установка EasyGui
Вам потребуется загрузить файл easygui.py или содержащий его zip-архив. Для установки
этот файл следует поместить туда, где его сможет обнаружить интерпретатор Python.
Где же находится это место?

Маршруты интерпретатора Python
На жестком диске есть ряд мест, в которых интерпретатор Python ищет свои модули.
В Windows, Mac OS X и Linux они располагаются по разным адресам. Но если поместить
файл easygui.py туда, где установлен сам интерпретатор Python, он без проблем будет
обнаружен. Поэтому найдите на жестком диске своего компьютера папку Python27
и скопируйте туда файл easygui.py.

Приступаем к созданию GUI-интерфейса
Запустите IDLE и в интерактивном режиме наберите следующее:

 >>> import easygui

Так вы проинформируете интерпретатор Python о своем намерении воспользоваться
модулем EasyGui. Если сообщение об ошибке не появится, значит, модуль был успешно
обнаружен. В случае же сообщения об ошибке следует зайти на сайт книги (www.manning.
com/books/hello-world-second-edition) и прочитать дополнительную инструкцию.
Теперь создадим простое информационное окно с кнопкой OK:

 >>> easygui.msgbox("Hello There!")
