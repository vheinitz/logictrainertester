В программе всего 18 директивных строк для Python плюс несколько пустых строк,
чтобы было удобнее читать. У вас не должно уйти много времени на то, чтобы набрать
весь код. Не переживайте, если не поймете, что означает каждая из директив. Совсем
скоро мы дойдем и до этого.

 Листинг 1.2. Игра «Угадай число»
 import random
 secret = random.randint(1, 99)             Выбираем секретное число
 guess = 0
 tries = 0
 print "Эй на палубе! Я Ужасный пират Робертс, и у меня есть секрет!"
 print "Это число от 1 до 99. Я дам тебе 6 попыток."
 while guess != secret and tries < 6:        Получаем
     guess = input("Твой вариант?")          мнение
     if guess < secret:                      игрока
                                                            Разрешаем
         print "Это слишком мало, презренный пес!"          до 6 попыток
     elif guess > secret:
         print "Это слишком много, сухопутная крыса!"

     tries = tries + 1                                                                                                                          Подсчитываем число попыток

 if guess == secret:
     print "Хватит! Ты угадал мой секрет!"
 else:                                                                                                                                                                                                     В конце игры выводим
     print "Попытки кончились!"                                                                                                                                                                            сообщение на экран

     print "Это число ", secret
