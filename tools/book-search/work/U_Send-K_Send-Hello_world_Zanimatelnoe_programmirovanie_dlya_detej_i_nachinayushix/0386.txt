Так выглядит процесс создания класса timedelta и последующего вычитания двух дат:

 >>> import datetime
 >>> yesterday = datetime.datetime(2012, 10, 23) Получаем разницу между
                                                      двумя датами
 >>> tomorrow = datetime.datetime(2012, 10, 25)
 >>> difference = tomorrow - yesterday
 >>> print difference           Между завтра и послезавтра
 2 days, 0:00:00                умещается 2 дня
 >>> print type(difference)
                                            Разница является объектом timedelta
 <type 'datetime.timedelta'>

Обратите внимание, что результатом вычитания двух объектов datetime является не
еще один объект datetime, а объект timedelta. Это преобразование интерпретатор
Python выполняет автоматически.

Маленькие фрагменты времени
До сих пор мы рассматривали время, измеряемое в секундах. Но объекты времени (date,
time, datetime и timedelta) поддерживают куда большую точность. С их помощью
можно измерять даже микросекунды, что составляет одну миллионную долю секунды.
В качестве примера рассмотрим метод now(), сообщающий текущие показания встро-
енных в компьютер часов:

 >>> print datetime.datetime.now()
 2012-10-24 21:25:44.343000

Обратите внимание, что результат работы этого метода содержит не секунды, а доли
секунд:

 44.343000

На моем компьютере последние три цифры всегда равны нулю, так как часы в моей
операционной системе отсчитывают только миллисекунды (тысячные секунд). С моей
точки зрения, это более чем достаточная точность!
Важно знать, что хотя эти данные имеют вид числа с плавающей точкой, хранятся они как
два целых числа, отдельно указывающих количество секунд и количество микросекунд:
44 секунды и 343 000 микросекунды. Преобразовать эти данные в число с плавающей
точкой можно по специальной формуле. Предположим, у нас есть объект time с именем
some_time и вы хотите получить количество секунд в форме вещественного числа. Вот
как это делается:

 seconds_float = some_time.second + some_time.microsecond / float(1000000)
