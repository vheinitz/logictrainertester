Инициализация объекта
В момент создания объекта переменные size, color и direction не имели опре-
деленных значений. Они присваиваются уже готовому объекту. Но также существует
возможность задать свойства объекта в процессе его создания. Это называется инициа­
лизацией объекта.

             НОВЫЕ СЛОВА
              Термин инициализация (initializing) означает «полу-
              чение готового объекта с самого начала». Инициализи-
              руя элемент программного обеспечения, мы готовим его
              к применению, помещая в нужное нам состояние.


Одновременно с определением класса можно определить специальный метод __init__(),
который будет запускаться при каждом создании экземпляра класса. Передавая
в метод __init__() аргумент, вы получаете экземпляр с нужными вам свойствами
(листинг 14.3).

 Листинг 14.3. Добавление метода __init__()
 class Ball:
     def __init__(self, color, size, direction):
         self.color = color
         self.size = size                                Это метод __init__(),
         self.direction = direction                      с каждой стороны
                                                         от init по два нижних
      def bounce(self):                                  подчеркивания

          if self.direction == "вниз":
              self.direction = "вверх"
