Вот переменная myTeacher (мой учитель) с единственным значением (имя учителя):

                                myTeacher                    Mr. Wilson



А список (в данном случае — список имен моих друзей) напоминает строку значений,
связанных друг с другом:

                myFriends             Curtis        Karla        Jenn        Kim       Shaun



Но иногда нам требуется таблица из строк и столбцов (это отметки моих одноклассников
по математике, естествознанию, чтению и правописанию):

                   classMarks               Math       Science      Reading        Spelling

                                    Joe        55           63          77           81


                                    Tom        65           61          67           72


                                   Beth        97           95          92           88



Как сохранить таблицу данных? Вы уже знаете, что для хранения нескольких элементов
у нас служат списки. Поэтому отметки каждого ученика можно поместить в список:

 >>> joeMarks = [55, 63, 77, 81]
 >>> tomMarks = [65, 61, 67, 72]
 >>> bethMarks = [97, 95, 92, 88]

Еще можно создать список для каждого предмета:

 >>> mathMarks = [55, 65, 97]
 >>> scienceMarks = [63, 61, 95]
 >>> readingMarks = [77, 67, 92]
 >>> spellingMarks = [81, 72, 88]

Но что делать, если вы хотите сохранить всю эту информацию в одной структуре данных?
Чтобы создать единую структуру данных для оценок учеников по всем предметам, можно
написать такой код:

 >>> classMarks = [joeMarks, tomMarks, bethMarks]
 >>> print classMarks
 [[55, 63, 77, 81], [65, 61, 67, 72], [97, 95, 92, 88]]
