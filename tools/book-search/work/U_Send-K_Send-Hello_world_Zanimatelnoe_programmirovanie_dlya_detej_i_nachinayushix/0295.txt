Теперь откройте в IDLE новый файл и введите в него базовый PyQt-код (можете скопи-
ровать его из нашей первой программы):

 import sys
 from PyQt4 import QtCore, QtGui, uic

 form_class = uic.loadUiType("tempconv.ui")[0]

 class MyWindowClass(QtGui.QMainWindow, form_class):
     def __init__(self, parent=None):
         QtGui.QMainWindow.__init__(self, parent)
         self.setupUi(self)

 app = QtGui.QApplication(sys.argv)
 myWindow = MyWindowClass()
 myWindow.show()
 app.exec_()

Преобразование из Цельсия в Фаренгейты
Первым делом заставим работать функцию, преобразующую градусы Цельсия в градусы
Фаренгейта. Вот формула, по которой осуществляется преобразование:
                              fahr = cel × 9.0 / 5 + 32.
Температуру в градусах Цельсия программа должна узнавать от виджета Line Edit, ко-
торый называется editCel, и после расчетов помещать результат в виджет Spin Box
