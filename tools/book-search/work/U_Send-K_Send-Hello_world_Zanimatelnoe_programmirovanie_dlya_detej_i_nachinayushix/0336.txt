Метод readline() читает по одной строке за раз, поэтому ему нет нужды помещать
результат в список. Каждое применение метода readline() дает вам одну строку.

Возвращение к началу
Если после многократного применения метода readline() возникает необходимость
вернуться к началу файла, воспользуйтесь методом seek():

 first_line = my_file.readline()
 second_line = my_file.readline()
 my_file.seek(0)
 first_line_again = my_file.readline()

Метод seek() заставляет интерпретатор Python перейти к указанному вами месту в фай-
ле. Число в скобках обозначает количество байтов от начала файла. Тот есть параметр 0
возвращает вас в самое начало.

Текстовые и бинарные файлы
Приведенные примеры открытия файлов и чтения оттуда предполагали наличие в файле
текста. Но напоминаю, что текст является всего лишь одним из типов данных, которые
можно сохранить в файле. Все остальные виды файлов программисты относят к катего-
рии, которая называется двоичными, или бинарными, файлами.
Существует два основных типа файлов, которые вы можете открыть.
   Текстовые файлы содержат внутри текст с буквами, цифрами, знаками препинания
     и специальными символами, например символами перевода строки.
   Двоичные файлы не содержат внутри текста. Внутри может находиться графика,
     музыка, какие-то данные, но разбиение на строки там отсутствует, так как отсут-
     ствуют символы переноса строк.
То есть вы не можете применять методы readline() и readlines() к двоичным файлам.
Попытавшись прочитать «строку» из файла с расширением .wav, вы получите неизвестно
что. Скорее всего, это будет какая-то такая абракадабра:

 >>> f = open('splat.wav', 'r')
 >>> print f.readline()
