      1. В интерактивном режиме ваши инструкции должны выглядеть примерно так:
         >>> first = 'Уоррен'
         >>> last = 'Сэнд'
         >>> print first + last
         УорренСэнд
         Ой! Пробел отсутствует. Можно добавить пробел после имени:
         >>> first = 'Уоррен '
         Можно также задействовать такой код:
         >>> print first + ' ' + last
         Уоррен Сэнд
         Еще можно воспользоваться запятой:
         >>> first = 'Уоррен'
         >>> last = 'Сэнд'
         >>> print first, last
         Уоррен Сэнд
