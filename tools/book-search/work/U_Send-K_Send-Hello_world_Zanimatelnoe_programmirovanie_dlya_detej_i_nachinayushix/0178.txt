Но если вы хотите вывести какую-то другую информацию, связанную с объектом, нужно
определить собственный метод __str__(), который переопределит встроенный метод.
Пример такого поведения рассмотрен в листинге 14.4.

 Листинг 14.4. Использование метода __str__() для изменения выводимой
 на экран информации
 class Ball:
     def __init__(self, color, size, direction):
         self.color = color
         self.size = size
         self.direction = direction




                                                                              Это метод __str__()
     def __str__(self):
         msg = "Привет, я " + self.size + " " + self.color + " мяч!"
         return msg
 myBall = Ball("красный", "маленький", "вниз")
 print myBall

Это выглядит понятнее, чем <__main__.Ball instance at 0x00BB83A0>. Имена всех
«волшебных» методов снабжаются двумя нижними подчеркиваниями с каждой стороны.
