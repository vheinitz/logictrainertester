Как именно работает код внутри этого цикла while? Там используется цикл событий
Pygame-модуля. Подробно он будет рассмотрен в главе 18, когда речь пойдет о Pygame-
событиях.

Рисование в окне
Итак, у нас есть Pygame-окно, которое остается открытым, пока мы не захотим его закрыть,
после чего оно аккуратно закроется. Цифры [640, 480] в третьей строке листинга 16.2
задают размер нашего окна: 640 пикселов в ширину и 480 в высоту. Давайте в нем что-
нибудь нарисуем. Измените вашу программу, чтобы она выглядела так, как показано
в листинге 16.3.

 Листинг 16.3. Рисование круга
 import pygame, sys
 pygame.init()                                  Заливаем окно
 screen = pygame.display.set_mode([640,480])    белым цветом
 screen.fill([255,255,255])                                                 Добавляем
 pygame.draw.circle(screen, [255,0,0],[100,100], 30, 0)                     эти три
                                                                            строки
 pygame.display.flip()
 running = True                Опрокидываем ваш
                               монитор… Шучу!           Рисуем круг
 while running:
     for event in pygame.event.get():
         if event.type == pygame.QUIT:
 running = False
 pygame.quit()
