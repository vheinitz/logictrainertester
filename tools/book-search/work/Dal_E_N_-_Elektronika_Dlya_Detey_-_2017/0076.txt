                    Шаг 4. Последовательное соединение лимонных элементов
                    Чтобы получить более высокое напряжение, нужно соединить все
                    четыре элемента последовательно. Для последовательного соединения
                    двух лимонов нужно просто соединить положительный вывод одного
                    с отрицательным выводом другого (вспомните, что медный провод поло-
                    жителен, а гвоздь отрицателен). Поэтому обмотайте конец медного про-
                    вода одного лимона вокруг гвоздя другого.
                        отрицательный (–)                    отрицательный (–)


                                              положительный (+)           положительный (+)




                        Чтобы последовательно соединить все четыре лимона, проделайте
                    эту операцию три раза. Выложите лимоны в ряд так, чтобы медный
                    провод каждого был справа, и присвойте им номера 1, 2, 3 и 4, начиная
                    слева. Обмотайте медный провод лимона 1 вокруг гвоздя лимона 2 так,
                    чтобы они не разъединились.
                        Затем обмотайте медный провод лимона 2 вокруг гвоздя лимона 3,
                    а медный провод лимона 3 вокруг гвоздя лимона 4. Получится ряд
                    из четырех лимонов, а неприсоединенными останутся только гвоздь
