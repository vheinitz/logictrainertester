Шаг 4. Суммирование чисел
Вы должны были получить три ряда чисел. Сложите все числа нижнего
ряда (удобно будет проставить плюсы между ними), и вы получите
запись этого числа в десятичной форме:




   значения позиций     128 64        32 16        8     4    2   1

              цифры      1 0 1 1 0 1 0 1
       суммируемые
           значения     128 + 0 + 32 + 16 + 0 + 4 + 0 + 1 = 181


   Итак, в десятичной форме число 1011 0101 имеет вид 181. Если у вас
получилось другое число, проверьте каждый шаг своей работы, чтобы
найти ошибку.
