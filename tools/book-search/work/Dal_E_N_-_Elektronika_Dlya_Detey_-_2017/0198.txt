Шаг 4. Проверка цветов
                   Подсоедините разъем батарейки к шинам питания на правой стороне
                   платы, подключите к нему батарейку и испытайте схему. Нажмите
                   любые кнопки задания цвета, а затем кнопку показа цвета. На фото
                   внизу изображен результат нажатия кнопки зеленого цвета.




                      В зависимости от того, какие кнопки нажаты, вы должны видеть
                   один из следующих семи цветов:

                    Цвет             Верхняя кнопка    Средняя кнопка    Нижняя кнопка

                    Красный          Нажата ( 1 )      Не нажата ( 0 )   Не нажата ( 0 )

                    Зеленый          Не нажата ( 0 )   Нажата ( 1 )      Не нажата ( 0 )

                    Синий            Не нажата ( 0 )   Не нажата ( 0 )   Нажата ( 1 )

                    Желтый           Нажата ( 1 )      Нажата ( 1 )      Не нажата ( 0 )

                    Зелено-голубой   Не нажата ( 0 )   Нажата ( 1 )      Нажата ( 1 )

                    Пурпурный        Нажата ( 1 )      Не нажата ( 0 )   Нажата ( 1 )

                    Белый            Нажата ( 1 )      Нажата ( 1 )      Нажата ( 1 )


                      Если ваши кнопки не соответствуют трем первым цветам этой та-
                   блицы, поменяйте провода у резисторов так, чтобы они соответствовали.
