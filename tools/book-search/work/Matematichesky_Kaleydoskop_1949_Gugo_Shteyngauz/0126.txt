112. Бумажная лента, скрученная на 180° и склеенная 
своими концами, образует так называемый ласт Мёбиуса. 
Он является односторонней поверхностью: муха, гуляющая 
по такой ленте, может переползти в любую её точку без  
неприятных для неё переходов через край ленты (например, из 
точки А в точку В). Эту поверхность невозможно выкрасить 
так, чтобы одна сторона была красная, а другая — зелёная: 
у неё есть только одна сторона. Край мёбиусова листа 
состоит из одной замкнутой кривой без узлов.
